[작업 목표]
map.html의 카카오맵에 '일반지도(다크모드)'와 '위성사진(스카이뷰+라벨)'을 전환할 수 있는 토글 버튼을 추가해줘.

[필수 구현 사항]
1. 지도 타입 전환 버튼 UI 추가
   - 지도 우측 상단(또는 줌 컨트롤 위)에 현재 다크모드 디자인과 어울리는 `[일반지도] / [위성사진]` 토글 버튼 배치.
   - 클릭 시 카카오맵 타입을 `kakao.maps.MapTypeId.ROADMAP` ↔ `kakao.maps.MapTypeId.HYBRID`(위성사진 + 단지명/도로명 표시)로 전환할 것.

2. 위성사진 모드 시 다크모드 CSS 필터 자동 해제 (핵심)
   - `ROADMAP`(일반지도) 상태일 때만 지도 타일 레이어에 다크모드 필터(`invert...`)를 적용하고,
   - `HYBRID`(위성사진)로 전환되면 지도 타일의 다크모드 필터를 즉시 제거(`filter: none`)해 실제 위성사진 색상이 왜곡 없이 선명하게 보이도록 처리할 것.
   - 주황색 숫자 클러스터 마커와 좌측 매물 리스트 동기화 기능은 두 모드 모두 동일하게 유지할 것.

[엄격한 제약 사항 (Code Lock)]
- 기존 map.html의 클러스터링, 필터링, 매물 상세 연동 로직 및 index.html, SEO 관련 파일은 절대 훼손하지 말 것.
- 작업 완료 후 GitHub 커밋/푸시 및 Vercel 배포 후 정상 동작 확인해줘.
