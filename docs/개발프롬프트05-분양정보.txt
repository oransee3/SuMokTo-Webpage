분양 정보 프롬프트

//===================================

4개 이후에는 상, 하 스크롤 바를 이용해서 아래, 위로 움직이도록하고, 8개이상 부터는 페이지 하단에 넘버가 나오도록 해줘. 
프로그램은 거의 100% 완성되었으므로 코드블록에 락을 걸어서 수정 부분만 수정하여 100% 완성해줘.

[완료 내역]
1. 분양 정보 모달 4개 이후 상·하 스크롤바 작동 구현:
   - 리스트 컨테이너 높이를 4개 단지 높이(max-h-[435px] sm:max-h-[455px])로 정밀 최적화.
   - 4개 이후(5번째 단지부터)는 부드러운 전용 상·하 스크롤바(sub-custom-scrollbar)를 통해 마우스 휠, 드래그, 터치로 아래·위 이동 지원.
2. 8개 이상부터 하단 페이지 넘버(Pagination) 자동 노출 시스템 구축:
   - 대전 도안신도시 및 인근 핵심 분양 단지 총 8개 구축 (힐스테이트 도안리버파크, 도안 푸르지오 디아델, 도안 프리미엄 상가, 도안 2단계 신규 후속 공급 예정 단지, 도안 우미린 트리쉐이드, 힐스테이트 도안퍼스트, 관저 푸르지오 센트럴파크, 대전 유성 하늘채 리버뷰).
   - 전체 단지 수가 8개 이상일 때 하단에 [ ‹ ] [ 1 ] [ 2 ] [ › ] 넘버링 버튼 및 (총 8개 단지) 안내 표시.
   - 페이지 번호 클릭 시 해당 페이지 목록으로 전환되며 상·하 스크롤 위치가 자동으로 맨 위로 초기화.
   - 단지 수가 8개 미만일 경우에는 하단 페이지 넘버가 자동으로 숨겨지도록 조건부 렌더링 적용.
3. 전역 파일 일괄 적용:
   - js/subscription_modal.js 분양 전용 고성능 모듈 신규 생성.
   - index.html, complex.html, complex_ipark.html, floor.html, floor_ipark.html 전역 연동.
4. PWA Service Worker v10 업데이트 및 실서버 배포/검증 완료.
